# قدّها | QADHA — عالم المغامرة المالية

**فلوسك. اختياراتك. مغامرتك.**

نموذج لعبة ويب عربية RTL للتثقيف المالي. تتحرك اللاعبة داخل عالم كرتوني، تجمع مكافآت، تحل متاهات وألغاز Match‑3، وتتعلم من قرارات مالية قصيرة من الحياة اليومية.

## التشغيل

المشروع لا يحتاج تثبيت حزم أو Backend أو API.

من داخل مجلد `qadha`:

```powershell
python -m http.server 4173
```

ثم افتحي `http://127.0.0.1:4173`.

## اختبارات Phase 1

يوجد مسار Playwright للانحدارات الحرجة في `tests/phase1-regression.js`. شغّلي الخادم أولًا، وتأكدي أن حزمة `playwright` متاحة لـNode، ثم:

```powershell
node tests/phase1-regression.js
```

## أساس Phase 2A

- تستخدم الواجهة شعار QADHA الرسمي من `assets/brand/` بدل الشعار المرسوم داخل CSS.
- اللون الرسمي المستخرج من الشعار هو Forest Green `#1F4A36`.
- توجد Design Tokens مستقلة في `css/tokens.css` وقواعد تأسيسية في `css/foundation.css`.
- ملفات CSS البنفسجية القديمة محفوظة، لكنها لم تعد محمّلة داخل التطبيق الحالي.
- توجد بنية ترجمة مركزية لـ`ar-EG` و`en`. العربية المصرية هي الافتراضية.
- محركات الألعاب ومنطق التقدم لم تتغير في Phase 2A.

اختبار الأساس:

```powershell
node tests/phase2a-foundation.js
```

يغطي الشعار الرسمي، ألوان الهوية، عزل CSS القديم، حفظ اللغة، RTL/LTR، التباين، وعدم وجود overflow عبر الموبايل والتابلت والديسكتوب.

## Phase 2B

- أضيفت ملفات WOFF2 محلية مرخّصة للخطوط Alexandria وNoto Sans Arabic وManrope مع نسخ تراخيص SIL OFL.
- أصبح مفتاح العربية/English ظاهرًا وقابلًا للوصول بالكيبورد في Welcome وOnboarding والهيكل العام والإعدادات.
- تحفظ اللغة المختارة في `LocalStorage` وتستمر بعد إعادة التحميل من دون المساس بالتقدم أو XP.
- أُعيد تصميم Welcome وOnboarding وHome والهيكل العام للديسكتوب والموبايل مع دعم RTL وLTR كامل لهذه الشاشات.
- بقيت محركات الألعاب ومنطق المكافآت والتقدم دون إعادة تصميم أو تغيير.

اختبار Phase 2B:

```powershell
node tests/phase2b-redesign.js
```

يغطي التحميل الفعلي للخطوط المحلية، غياب طلبات الخطوط الخارجية، مفتاح اللغة، حفظ التفضيل، سلامة بيانات التقدم، وعدم وجود تمرير أفقي عبر المقاسات الرئيسية.

يمكن تغيير عنوان الخادم عبر `QADHA_BASE_URL` ومسار Chrome عبر `QADHA_CHROME`. الاختبار يغطي التقدم بعد الخسارة، منع تكرار XP، تنظيف جلسات اللعب، مهام اليوم، Match-3، الـHUD عبر أربعة مقاسات، وأساسيات الوصول.

## التجربة الأساسية

- شخصية الدليل الأصلية **LUMA** بتعبيرات متعددة.
- أربع شخصيات قابلة للاختيار مع ملابس وإكسسوارات تُفتح بالـXP.
- خريطة عالم من خمس مناطق، مع شروط فتح واضحة.
- **Budget Dash** — Endless Runner حقيقي بثلاث حارات، قفز، انزلاق، تصادم، مقتنيات ونقاط قرار.
- **Scam Hunter** — متاهة مولّدة قابلة للحركة بالأسهم وWASD واللمس، مع أدلة ورسائل مشبوهة وبوابة تحقق.
- **Grow Your Goal** — Match‑3 قابل للعب، مبادلة رموز، سقوط وتجدد، combo، حركات محدودة ونمو حديقة الهدف.
- خمس ألعاب صغيرة تعمل بالكامل.
- Financial Plaza تفاعلية وChallenge Island بتحدٍّ مختلط.
- مخطط ميزانية، محاكي هدف ادخار، ومحاكاة جمعية تعليمية.
- 10 دروس قصيرة و15 مصطلحًا ماليًا.
- XP ومستويات وأوسمة ونجوم ومقتنيات ومهمة يومية.
- مؤثرات صوتية أصلية مولّدة داخل المتصفح من دون ملفات خارجية.
- إعدادات الصوت والموسيقى الاختيارية وتقليل الحركة.
- حفظ محلي كامل ومنع تكرار مكافآت المستويات المكتملة.
- Reset Demo للعودة إلى البداية قبل العرض.

## التحكم

### Budget Dash

- الأسهم يمين ويسار لتغيير الحارة.
- السهم لأعلى أو Space للقفز.
- السهم لأسفل للانزلاق.
- Swipe وأزرار شاشة على الموبايل.

### Scam Hunter

- الأسهم أو WASD.
- أزرار اتجاه على الموبايل.

### Grow Your Goal

- اختاري رمزًا ثم رمزًا ملاصقًا لتبديلهما.

## رحلة عرض 3–5 دقائق

1. اختاري **وضع العرض السريع** لفتح العالم كله، أو اعرضي onboarding واختيار الشخصية.
2. ابدئي Budget Dash وتحركي واقفزي واجمعي نجمة.
3. افتحي Scam Hunter وتحركي نحو علامة `!` لفحص رسالة.
4. افتحي Grow Your Goal ونفذي مبادلة صحيحة.
5. اعرضي لعبة صغيرة، درسًا، صفحة التقدم ومختبر التخطيط.
6. استخدمي Reset Demo من إعدادات الحساب قبل العرض التالي.

## حدود النموذج

- جميع الأموال والأرصدة والمساهمات والمكافآت خيالية.
- لا توجد مدفوعات أو حسابات أو تحويلات أو منتجات مالية حقيقية.
- التخزين على نفس المتصفح والجهاز فقط.
- المحتوى تعليمي عام، ولا يمثل نصيحة مالية أو مصرفية أو استثمارية شخصية.
- لم تُجرَ بعد دراسة مستخدمات أو تجربة أثر تعليمي ميدانية.
