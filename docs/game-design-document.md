# وثيقة تصميم ألعاب قدّها

## مبادئ التصميم

- اللعب يسبق الشرح الطويل.
- كل حركة تعليمية لها أثر مرئي أو مكافأة.
- الخطأ يقدم تفسيرًا وتشجيعًا.
- المهام قصيرة ومناسبة للموبايل ولعرض المسابقة.
- لا توجد آليات pay-to-win أو عقاب على فقدان سلسلة أيام.

## Budget Dash

**النوع** Endless Runner بثلاث حارات.

**المدخلات** الأسهم، Space، Swipe وأزرار لمس.

**الحركات** تغيير الحارة، القفز والانزلاق.

**العوائق** عربات شراء اندفاعية، فواتير، اشتراكات، حواجز ولافتات تحتاج انزلاقًا.

**المقتنيات** نجوم ادخار، رموز اختيار ذكي ودروع طوارئ.

**التعلم** تظهر نقاط قرار أثناء الجري. القرار الجيد يضيف نقاطًا، وكل اختيار يعرض تفسيرًا.

**المراحل** خمس مراحل بسرعات ومسافات وتكرار عوائق متزايد.

## Scam Hunter

**النوع** متاهة ومغامرة أدلة.

**المدخلات** الأسهم، WASD وأزرار لمس.

**توليد المتاهة** خوارزمية DFS seeded تنتج شكلًا ثابتًا مختلفًا لكل مستوى.

**العناصر** أدلة `!`، محطة تحقق `✓`، نجمة مخفية وبوابة خروج مقفلة.

**التعلم** فحص الدليل يعرض رسالة احتيال، ثم علامات مثل الاستعجال والرابط وطلب الكود السري. يلزم جمع الأدلة لفتح البوابة.

**المراحل** خمس متاهات بأحجام 9×9 حتى 17×17 وعدد أدلة متزايد.

## Grow Your Goal

**النوع** Match‑3 وحديقة نمو.

**العناصر** بذور وأوراق ومياه وشمس وحصالة ونجمة مميزة.

**القواعد** تبديل عنصرين متجاورين، قبول المبادلة عند تكوين تطابق، حذف العناصر، سقوط الموجود وتجديد الشبكة.

**المكافآت** combo يضاعف النقاط، وتطابق 4 أو أكثر يمنح نجمة خاصة.

**التعلم** كل أربع حركات تظهر لحظة تخطيط مرتبطة بهدف الادخار والمرونة.

**المراحل** خمس مراحل بأحجام وأهداف وحركات مختلفة.

## الألعاب الصغيرة

1. **Spend Sort** — ضغط أو سحب بطاقات إلى احتياجات ورغبات وادخار وطوارئ.
2. **Smart Shopping** — اختيار قائمة أساسية داخل ميزانية محدودة.
3. **Spot the Scam** — لمس عناصر الرسالة المشبوهة.
4. **The Savings Path** — مسار قرارات متفرع.
5. **Money Memory** — مطابقة المصطلح بتعريفه.

## التقدم والمكافآت

- مكافأة المستوى تُحسب مرة واحدة.
- تحسين أفضل نتيجة يمنح مكافأة صغيرة فقط.
- XP يفتح مناطق وإكسسوارات ورتبًا.
- النجوم والرموز والدروع محفوظة محليًا.
- مهمة يومية اختيارية من دون خسارة أو عقاب.

## الصوت والحركة

المؤثرات مولدة عبر Web Audio API عند تفاعل المستخدمة. لا يبدأ صوت مرتفع تلقائيًا. يمكن إيقاف المؤثرات والموسيقى وتقليل الحركة.
